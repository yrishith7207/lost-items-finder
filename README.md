# Lost Items Finder

A simple web app for reporting and finding lost items in your community.

## Features

- Report a lost or found item (name, category, description, place, date, contact)
- Search by name, place or description
- Filter by lost / found and by category
- Mark items as returned, or delete them
- Reports are saved in your browser (localStorage)

## Run it

Requires [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install
npm run dev
```

The app opens at http://localhost:5173. Press `Ctrl + C` in the terminal to stop it.

## Build for production

```bash
npm run build
npm run preview
```
